# Preparar la publicación de tu aplicación Android

La SDK admite la optimización de código y recursos con R8. Conserva las dependencias y versiones de la [guía de integración](../INSTALACION.md#instalación).

## Configuración

Si tu aplicación utiliza optimización, configura su versión de publicación en `app/build.gradle`:

```groovy
android {
    buildTypes {
        release {
            minifyEnabled true
            shrinkResources true
            proguardFiles getDefaultProguardFile('proguard-android-optimize.txt'),
                'proguard-rules.pro'
        }
    }
}
```

Las reglas necesarias para la SDK se incluyen en el AAR y se aplican automáticamente. Mantén en `proguard-rules.pro` las reglas específicas de tu aplicación; no necesitas agregar una regla general para conservar toda la SDK.

Para la configuración con el complemento de Android 9.0.1, elimina de `gradle.properties` los ajustes `android.nonFinalResIds=false`, `android.r8.strictFullModeForKeepRules=false` y `android.r8.optimizedResourceShrinking=false` si todavía los utilizas.

## Comprobar la versión de publicación

Genera la versión de publicación desde Android Studio y verifica en un dispositivo físico los permisos, captura de documento y rostro, revisión, reintento, cancelación, traducciones y recepción de resultados.

Conserva el archivo de correspondencias de R8 de cada versión publicada para poder revisar incidencias de esa versión con tu equipo de soporte.
